# Tag&Release 规范

## 版本号

遵守 `v<主版本号>.<次版本号>.<修订版本号>` 格式,例如 `v0.1.0`

> README的版本徽章显示文字中,版本号不带v字母前缀

## Tag

遵守 `<版本号>` 格式

## Release

遵守 `<版本号>-dsh-<受支持的dsh版本号>` 格式,例如 `v0.2.1-dsh-0.2.0-rc.2`

同时支持多个dsh版本时,把受支持版本按升序并联进名称,例如 `v0.2.3-dsh-0.2.0-rc.2+0.2.1-rc.1`

> 本插件的Release绑定的dsh版本集合,必须与 `package.json` 的 `engines.dsh` 及dsh前缀peer的取值范围一致(见 `AGENTS.md` 设计细节的 宿主版本兼容性 条目)
>
> 名称里列出的每个dsh版本都必须是实际核对过的受支持版本,不得为了覆盖更广而写入未验证的版本;新增受支持版本时,既迭代插件版本号并发布新的Release,也同步更新 `engines.dsh` 与dsh前缀peer
